## Правила отклика (из данных по рынку 2026)

1. **76% компаний фильтруют резюме автоматически, буквально по словам.** Резюме
   под каждую вакансию подгонять по ключевым словам из её текста: Spring,
   Hibernate, PostgreSQL, Kafka, Docker и так далее. Нет слова в резюме — нет
   совпадения — отклик не дойдёт до человека.
2. **10–15 точных откликов в неделю лучше, чем сто одинаковых.**
3. **Если компания крупная, сначала искать форму на её сайте**, hh только
   дублировать: отклики там режутся автофильтрами незаметно для кандидата.
4. **Ходить на все собеседования, куда зовут**, даже если работать там не
   собираешься. Практика прохождения собесов сама по себе актив.
5. Не отсеивать по «скучной отрасли». Охрана, логистика, промышленность,
   госсектор пишут на том же стеке, а конкуренции там кратно меньше.
