## 1. Описание информационной системы

**Назначение:** мониторинг цен на товары маркетплейсов по запросу пользователя
и направление уведомлений об их изменении.

**Состав:**

- один виртуальный сервер (VPS) у хостинг-провайдера на территории Российской
  Федерации; приложения выполняются в контейнерах в изолированной сети;
- СУБД PostgreSQL — основное хранилище персональных данных;
- Redis — кэш и служебные ключи;
- Apache Kafka — очереди событий;
- Grafana Loki, Prometheus, Grafana, Alertmanager — сбор логов, метрик и
  оповещений;
- nginx — обратный прокси, единственная точка входа из сети Интернет
  (порты 80/443);
- резервное копирование СУБД с зеркалированием в объектное хранилище S3
  (Selectel, регион ru-1, Российская Федерация).

**Каналы взаимодействия с субъектами:** Telegram (получение обновлений методом
опроса), ВКонтакте и MAX (входящие вызовы через nginx), веб-сайт tryberry.ru
(только чтение, персональные данные через формы сайта не собираются).

**Тип ИСПДн:** информационная система, обрабатывающая иные категории
персональных данных субъектов, не являющихся работниками Оператора.

## 2. Определение уровня защищённости

| Параметр | Значение |
|---|---|
| Категория персональных данных | иные |
| Отношение субъектов к Оператору | субъекты не являются работниками Оператора |
| Количество субъектов | менее 100 000 |
| Актуальный тип угроз | **3-го типа** — угрозы, не связанные с наличием недокументированных (недекларированных) возможностей в системном и прикладном программном обеспечении |

**Обоснование типа угроз.** Оператор использует общедоступное системное и
прикладное программное обеспечение (Linux, Docker, PostgreSQL, Redis, Kafka,
nginx) в актуальных версиях, полученное из официальных источников. Сведения о
наличии в нём недокументированных возможностей отсутствуют; целенаправленные
атаки уровня разработчика программного обеспечения для сервиса указанного
масштаба не рассматриваются как актуальные.

**Вывод: требуется обеспечение 4-го (низшего) уровня защищённости персональных
данных** в соответствии с п. 13 Требований, утв. постановлением Правительства РФ
от 01.11.2012 № 1119.

## 3. Актуальные угрозы и меры противодействия

| № | Угроза | Актуальность | Реализованные меры |
|---|---|---|---|
| 1 | Несанкционированный доступ к серверу извне (подбор учётных данных, эксплуатация открытых сетевых служб) | **актуальна** | доступ по SSH только по ключу; парольная аутентификация и вход `root` по паролю отключены; сетевой экран разрешает извне только 80/443 и порт SSH; порты СУБД, кэша и брокера сообщений недоступны из сети Интернет; правила сетевого экрана персистентны и применяются в том числе к цепочке `DOCKER-USER` |
| 2 | Компрометация данных при передаче по сети | **актуальна** | HTTPS с сертификатом Let's Encrypt и автоматическим обновлением; включён HSTS; заголовки безопасности; взаимодействие с платёжным сервисом и мессенджерами — только по TLS |
| 3 | Внедрение SQL-кода, некорректная обработка входных данных | **актуальна** | все обращения к СУБД — через параметризованные запросы; входные данные пользователя валидируются; прикладная учётная запись СУБД не обладает правами суперпользователя |
| 4 | Компрометация секретов (паролей, токенов, ключей доступа) | **актуальна** | секреты хранятся вне системы контроля версий, в файле окружения на сервере с ограниченными правами; документированный порядок плановой и внеплановой ротации (`docs/SECRET-ROTATION-RUNBOOK.md`) |
| 5 | Подделка входящих вызовов от внешних сервисов (уведомления платёжного сервиса, входящие сообщения мессенджеров) | **актуальна** | проверка подписи уведомлений платёжного сервиса; проверка секрета входящих вызовов мессенджеров; идемпотентная обработка повторных уведомлений |
| 6 | Несанкционированный доступ к сведениям иного пользователя внутри сервиса | **актуальна** | все выборки данных ограничены идентификатором обратившегося пользователя; административные команды доступны только идентификаторам из конфигурации |
| 7 | Утрата данных вследствие отказа оборудования или ошибочных действий | **актуальна** | ежесуточное резервное копирование СУБД с ротацией (7 суточных, 4 недельных, 6 месячных копий) и зеркалированием в объектное хранилище на территории Российской Федерации |
| 8 | Компрометация данных на стороне лица, действующего по поручению Оператора | **актуальна** | выбор организаций, обеспечивающих требования законодательства Российской Федерации о персональных данных; минимизация объёма передаваемых данных; платёжные реквизиты Оператору не передаются |
| 9 | Несанкционированный доступ к резервным копиям в объектном хранилище | **актуальна** | доступ к бакету только по ключам доступа, хранящимся в файле окружения; копии передаются по TLS; бакет не является публичным |
| 10 | Действия лица, имеющего легальный доступ (внутренний нарушитель) | **малоактуальна** | Оператор — единственное лицо, допущенное к обработке; работники и подрядчики с доступом к ИСПДн отсутствуют; при появлении таких лиц угроза подлежит переоценке |
| 11 | Угрозы, связанные с недокументированными возможностями системного и прикладного ПО | **неактуальна** | обоснование — раздел 2; используется общедоступное ПО из официальных источников, версии поддерживаются в актуальном состоянии |
| 12 | Угрозы, связанные с несанкционированным физическим доступом к оборудованию | **неактуальна для Оператора** | оборудование размещено в центре обработки данных хостинг-провайдера; физическая защита обеспечивается провайдером в рамках договора |

## 4. Модель нарушителя

| Тип | Возможности | Оценка |
|---|---|---|
| Внешний нарушитель, не обладающий сведениями об ИСПДн | массовое сканирование сети Интернет, подбор учётных данных, эксплуатация известных уязвимостей общедоступного ПО | **основной актуальный нарушитель** |
| Внешний нарушитель, обладающий сведениями об ИСПДн | целенаправленный анализ доступных интерфейсов сервиса, попытки подделки входящих вызовов | актуален |
| Внутренний нарушитель (лицо, допущенное к обработке) | полный доступ к данным | малоактуален: допущено единственное лицо — сам Оператор |
| Нарушитель, обладающий возможностями разработчика системного или прикладного ПО | использование недокументированных возможностей | неактуален (раздел 2) |
