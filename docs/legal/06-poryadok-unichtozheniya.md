## 1. Основания и сроки уничтожения

| № | Основание | Срок уничтожения |
|---|---|---|
| 1 | Достижение цели обработки либо утрата необходимости в достижении цели (ч. 4 ст. 21) | не более 30 дней с даты достижения цели |
| 2 | Отзыв субъектом согласия на обработку персональных данных, если обработка осуществлялась только на основании согласия (ч. 5 ст. 21) | не более 30 дней с даты поступления отзыва |
| 3 | Требование субъекта об уничтожении неправомерно обрабатываемых персональных данных, выявление факта неправомерной обработки (ч. 3 ст. 21) | не более 3 рабочих дней с даты выявления либо поступления требования |
| 4 | Истечение срока хранения, установленного документом «Перечень обрабатываемых персональных данных» | в течение установленного регламентом цикла обслуживания |

**Данные, не подлежащие уничтожению по требованию субъекта:** сведения о
совершённых платежах и связанные с ними данные, хранение которых Оператор
обязан обеспечить в силу законодательства о налогах и сборах и о применении
контрольно-кассовой техники. Такие сведения блокируются для целей оказания
услуги и хранятся в течение установленного законом срока, после чего
уничтожаются в общем порядке.

## 2. Способы уничтожения

Обработка ведётся исключительно с использованием средств автоматизации;
материальные носители с персональными данными Оператором не используются.
Уничтожение производится способом, исключающим восстановление данных
и дальнейшую их обработку:

| Хранилище | Способ уничтожения |
|---|---|
| СУБД PostgreSQL | удаление записей субъекта из основной базы данных; связанные записи удаляются каскадно по внешним ключам |
| Redis | удаление ключей, содержащих идентификаторы субъекта; остальные ключи вытесняются по истечении срока жизни |
| Apache Kafka | сообщения удаляются автоматически по истечении срока хранения (72 часа); отдельные действия не требуются |
| Grafana Loki | записи удаляются автоматически по истечении срока хранения (30 суток); отдельные действия не требуются |
| Резервные копии (локальные и в объектном хранилище) | целевое удаление отдельных записей из копий не производится (технически несовместимо с назначением резервной копии); копии, содержащие уничтоженные данные, выводятся из обращения по мере штатной ротации — 7 суточных, 4 недельных, 6 месячных копий, то есть в срок не более 6 месяцев с даты уничтожения. Доступ к копиям в этот период ограничен Оператором; данные из них не используются для обработки, а восстановление производится только при аварии с последующим повторным применением произведённых удалений |

⚠️ Ограничение по резервным копиям должно быть отражено в ответе субъекту при
исполнении требования об уничтожении — субъекту сообщается, что его данные
удалены из рабочей системы и будут исключены из резервных копий в течение
не более 6 месяцев в связи с их штатной ротацией.

## 3. Подтверждение уничтожения

Поскольку обработка осуществляется с использованием средств автоматизации,
подтверждением уничтожения персональных данных служат **два документа
одновременно** (п. 2, 3 Требований, утв. приказом Роскомнадзора № 179):

1. **Акт об уничтожении персональных данных** — форма в разделе 5;
2. **Выгрузка из журнала регистрации событий в информационной системе
   персональных данных** — форма в разделе 6.

Оба документа составляются **в день уничтожения** и хранятся Оператором
**не менее 3 лет** с даты уничтожения.

## 4. Порядок действий

1. Зафиксировать основание уничтожения и дату его возникновения в журнале
   учёта обращений (`09-zhurnal-obrashcheniy.md`), если основанием послужило
   обращение субъекта.
2. Определить объём подлежащих уничтожению данных: все записи, связанные
   с субъектом, за исключением сведений, указанных в разделе 1 как не
   подлежащие уничтожению.
3. Выполнить удаление в порядке раздела 2. Действия выполняются лично
   Оператором.
4. Убедиться, что данные субъекта отсутствуют в рабочей системе (контрольная
   выборка по идентификаторам субъекта во всех каналах: Telegram, ВКонтакте,
   MAX).
5. Составить и подписать Акт об уничтожении и сформировать выгрузку из журнала
   регистрации событий.
6. Направить субъекту уведомление об исполнении требования — в срок,
   установленный Правилами рассмотрения запросов субъектов персональных данных.
