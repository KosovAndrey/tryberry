## Как это превратить в юридически значимые документы

Markdown в git — это **исходник**, сам по себе он ничего не подтверждает.
Порядок такой:

1. Вычитать текст под свою фактуру (места, где нужна твоя проверка, помечены `⚠️`).
2. Распечатать или экспортировать в PDF.
3. Подписать собственноручно с датой, либо подписать УКЭП.
4. Хранить: подписанные оригиналы — у себя (бумага или PDF с УКЭП),
   исходники — здесь, под версионированием.
5. При изменении фактуры (новый обработчик, новая категория ПД, смена хостинга)
   править исходник → переподписывать → и проверять, не требует ли изменение
   уведомления РКН (форма прил. № 2 к приказу № 180, срок — до 15-го числа
   месяца, следующего за месяцем изменения).
