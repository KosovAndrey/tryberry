# WB: переход цены карточки на u-card.wb.ru

Статус: **реализовано** (2026-06-22), ветка `feat/wb-ucard-price`.
Закрывает задачу «WB трансграничные/AliExpress товары».

## Зачем

Прежний WB-скрейпер (`internal/scraper/wildberries.go`) брал цену из basket-CDN
`price-history.json`. Три боли (по его же комментариям):
1. перебор basket-шардов (формула `wbBasketNumber` + соседи ±12);
2. цена **отстаёт на часы** (это последняя запись истории, не текущая);
3. **не видит трансграничные** товары («Находки из Китая», напр. `nm=1114323146`) —
   их нет в basket-CDN (перебор баскетов 1-46 пуст), а `card.wb.ru` даёт 404/403.

## Решение

Нашёлся открытый real-time эндпоинт карточки (живой наследник мёртвого card.wb.ru):

`https://u-card.wb.ru/cards/v4/list?appType=1&curr=rub&dest=-1257786&spp=30&nm={id}`

- открытый (без токена/антибота), отвечает 200 для любого nm, включая трансгран;
- цена в `products[0].sizes[0].price.product` (копейки) — **текущая** цена;
- форма ответа = поисковой выдаче → переиспользуем `wbSearchResponse`.

Проверено, что `product` = цена, которую видит юзер на сайте (живой ценник
ноутбука ≈167тыс совпал с `product`, а `price-history` показывал устаревшие
148тыс — он просто лагал). `spp` на `product` не влияет.

## Что сделано

- `Scrape` → сначала `fetchFromUCard` (основной), при ошибке → `fetchFromBasket`
  (fallback, прежний путь сохранён целиком).
- `ucardPriceKopecks`: `product` → фолбэк `total`/`basic`.
- u-card вернул цену 0 (нет оффера) → отдаём на basket-fallback, чтобы **не менять
  контракт** WB-скрейпера (он, как и раньше, не эмитит `InStock=false`).
- Метрика `tryberrybot_wb_price_source_total{source=ucard|basket}` — видно долю
  fallback на basket (если u-card начнёт сбоить — будет заметно).
- Картинка по-прежнему строится из basket (`wbImageURL`); для трансграничных
  может 404-ить (вторично, цена важнее).

## Проверить на VPS

- обычный товар: цена в боте совпадает с сайтом и берётся из u-card
  (`wb_price_source_total{source="ucard"}` растёт);
- трансграничный `nm=1114323146` теперь трекается (раньше — «не найдено»);
- доля `source="basket"` мала (fallback редкий).
