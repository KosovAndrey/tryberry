# Гайд по съёмке: каталоги (горизонт 1920×1080)

Пошаговый чеклист на день съёмки. Контекст и решения — в `docs/PRESS-SHOTS-PLAN.md`,
здесь только «что нажимать».

**Что снимаем:** 7 статичных кадров 1920×1080 для каталогов (волна 1:
tgstat + каталоги ботов, `docs/DIRECTORY-SUBMISSIONS.md` §28).
**Где:** ноут (Windows, HiDPI ~3072×1920), Telegram Desktop + браузер.
**Рилсы этим гайдом НЕ снимаются** — они вертикальные и с телефона, ждут сценариев.

---

## Шаг 0. Проверки до первого кадра (5 мин)

**Прод на `main`** — иначе кадр №2 отдаст старую цену и придётся переснимать.
Фикс OOS-цены = `aa9c3a6`. На ВПС:

```bash
cd ~/tryberrybot && git log --oneline -1
```

Должен быть `aa9c3a6` или новее. Если фич-ветка — стоп, сначала выкатываем.

**Свободный слот поисковой подписки.** Тариф Lite = **3 поисковых подписки**
максимум. Если заняты три — новую выдачу не добавить, сперва отписаться.

**Каданс Lite = 30 мин** (`internal/domain/plan.go:53`) — столько ждать алерт.

## Шаг 1. Настройка ноута под ретину

Смысл: снимаем в **физических** пикселях (~3072×1920), в After Effects
**уменьшаем** до 1920×1080. Уменьшение даёт плотный резкий кадр; увеличение не
даёт никогда. Поэтому снимаем крупнее цели, а не впритык.

1. **Масштаб экрана:** Параметры → Система → Дисплей → «Масштаб и разметка».
   Запиши значение (скорее всего 200 % или 250 %). Менять не надо — чем крупнее
   масштаб, тем крупнее текст в кадре.
2. **ShareX** (или Ножницы). В ShareX: Задачи → Настройки задач → «После захвата»
   оставить только **«Сохранить изображение в файл»**, выгрузку выключить,
   водяные знаки и эффекты выключить. Формат — **PNG**, не JPG.
3. **🔑 Проверка DPI-awareness — обязательно.** Сделай один тестовый снимок всего
   экрана и посмотри свойства файла. Должно быть **3072×1920**. Если там
   **1536×960** — инструмент захватывает логические пиксели, все кадры выйдут
   мылом. Тогда меняй инструмент (ShareX точно умеет).
4. **Тёмная тема** в Telegram и в браузере.
5. **«Не беспокоить»** — чтобы в кадр не влезли уведомления из других чатов.
6. Telegram Desktop — **почти на весь экран**. Так ширины гарантированно хватит с
   запасом на кроп.
7. Снимаем **окно**, не экран (в ShareX: Захват → Окно → Telegram) — так не
   попадёт панель задач.

Список чатов слева в кадр попадёт — закроешь маской в AE (шаг 4).

## Шаг 2. Порядок кадров — важен из-за таймера

Кадры №3 и №4 **создают подписку на выдачу**, а она через ~30 мин рождает кадр
№5. То есть, снимая №3–4, ты одновременно заводишь таймер. Пока тикает — снимаешь
всё остальное. Отдельно ждать не придётся.

```
№3 → №4  (завели подписку, пошёл таймер ~30 мин)
   ↓
№1, №2, №6, №7  (снимаем, пока ждём)
   ↓
№5  (прилетел алерт)
```

## Шаг 3. Кадры

### №3. Поиск по каталогу (снимать ПЕРВЫМ)
Кидаешь боту **ссылку на выдачу Я.Маркета** (очистители воздуха). Бот принимает
выдачу и предлагает поставить порог.
→ `press_search_by_url_1920x1080.png`

### №4. Выбор порога — **ключевой кадр, фича дня**
Ставишь порог **13 000 ₽**. В кадре: «📉 уведомлю, когда цена опустится ниже
13 000 ₽» (`domain/render.go:77`).
Почему именно порог, а не «любое падение»: у Xiaomi реальных срабатываний
`any_drop` было 12 штук за 9 дней — это шум. Один `below_target` = чистая история
за один кадр. Порог и есть то, что зритель поймёт сразу.
**Подбери так, чтобы в алерт попало 3–5 товаров, а не сорок** — список читается
как доказательство слежения за категорией, но только пока виден целиком.
→ `press_threshold_1920x1080.png`

### №1. Добавление товара по ссылке → карточка с ценой
Нужен **живой товар Я.Маркета в наличии** (Xiaomi не годится — он OOS).
Только Я.Маркет: Ozon (история вычищена), WB (97 % цен из архива) и Ali-поиск
(сайдкар 502) снимать нельзя — см. план §4.
→ `press_track_by_url_1920x1080.png`

### №2. Xiaomi: «нет в наличии, последняя цена 12 664 ₽»
Карточка `product_id 8298786`. Честен, работает на сюжет, панчлайн всей истории:
товара нет, потому что его забрал ты.
→ `press_oos_card_1920x1080.png`

### №6. График на сайте
Браузер, `https://tryberry.ru/p/9e02a4110d84`. В кадре — вердикт «Дешевле не было
за всё время наблюдения». Скрой панель закладок браузера.
→ `press_price_chart_1920x1080.png`

### №7. Тарифы
**Снимать экран ВЫБОРА тарифа. НЕ `/myplan`** — там твои username и email.
→ `press_plans_1920x1080.png`

### №5. Алерт списком (когда прилетит)
Настоящий алерт по выдаче. Текст (`internal/telegram/notifier.go:93`):
«📉 Цена снизилась! / Было X → Стало Y / Скидка Z (N %)» + вердикт honest_price +
фото + кнопка «📈 График цены».
Xiaomi в нём **не будет** — он OOS, оффера в выдаче нет. Это нормально.
→ `press_alert_list_1920x1080.png`

## Шаг 4. After Effects: кроп + даунскейл + маска

Экран 3072×1920 — это **16:10**, а цель 1920×1080 — **16:9**. Поэтому сначала
кроп, потом уменьшение.

1. Композиция **1920×1080**.
2. Импортировать PNG (~3072×1870).
3. Кадр шире композиции по пропорции — обрезать до **16:9** (3072×1728),
   выбрав по вертикали нужную часть переписки.
4. Уменьшить до композиции — это даунскейл ~1,6×. **Ничего не растягивать.**
5. **Маска на список чатов** слева (прямоугольник заливкой или блюром).
6. Экспорт: Композиция → Сохранить кадр как → Файл → PNG.

## Чего в кадр не пускать

- **`/myplan`** — username и email.
- **Список чатов** — маской (или кропом, если влезает).
- **Уведомления** из других чатов — «Не беспокоить».
- **ЛК Я.Маркета** (для кейса-реконструкции, не для каталогов) — там ФИО, адрес,
  телефон. Маскировать всё, кроме позиции и цены.

## Красная линия

Цифры бота не редактируем, скидок не дорисовываем, алертов не изготавливаем.
Мы продаём инструмент, который разоблачает нарисованные скидки нашим же публичным
графиком — на нём же и поймают. Честные 11 % сильнее фейковых 40 %.
Подробности решения — план §3.
