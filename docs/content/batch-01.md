# Батч №1 — 15 сценариев (пилот тест-матрицы)

Дата: 2026-07-21. Статус: сценарии готовы, производство не начато.
Канон: [PROMO-SHORTS-PLAN.md](../PROMO-SHORTS-PLAN.md) §4 (форматы), §7 (пайплайн).
Ассеты: [asset-library.md](asset-library.md).

Цель батча — не охват, а **проверка, что пайплайн ходит целиком**: сценарий →
хук → скринкаст → сборка → заливка → метка в `user_attribution`. По 3 ролика на
каждый из 5 форматов, чтобы после отсева брака осталось хоть что-то сравнимое.

Пропорция нативности: 6 прямых (F1, F2) / 3 гибрид (F3) / 6 нативных (F4, F5) =
**40 / 60**, как требует канон.

## Перед производством — обязательное

1. **Подобрать реальные товары.** Все цифры в F1/F2 помечены `⟨ПОДСТАВИТЬ⟩` —
   их берём из БД, а не выдумываем: `scripts/sql/shorts-candidates.sql`
   (блок F1 — «цена стоит ровно», блок F2 — «реальное падение в ₽»).
   Подрисовывать данные нельзя — это та же красная линия, что и в пресс-кадрах.
2. **Записать ассеты A1–A8, G1–G3, B1–B3** одной сессией (см. библиотеку).
   Батч на них стоит целиком: 12 сценариев из 15 не собираются без A-блоков.
3. **Демо-аккаунт**, тёмная тема, ноль личных данных в кадре.

## Матрица меток атрибуции

Метка на каждый ролик: `v_<формат>-<номер>_<площадка>`. Регистрировать нигде не
нужно — новый payload сам появится в `scripts/sql/attribution-report.sql`.

| Сценарий | Метка (семейство) | TG | VK |
|---|---|---|---|
| 01–03 | `v_f1-01…03` | `t.me/TryBerryBot?start=v_f1-01_yt` | `vk.me/tryberrybot?ref=v_f1-01_vk` |
| 04–06 | `v_f2-01…03` | …`_yt` / `_ig` / `_tt` по площадке | …`_vk` |
| 07–09 | `v_f3-01…03` | | |
| 10–12 | `v_f4-01…03` | | |
| 13–15 | `v_f5-01…03` | | |

Площадочный суффикс — `yt` / `vk` / `ig` / `tt`. Один и тот же ролик на четырёх
площадках = четыре разные ссылки.

**AI-генерация:** 12 клипов по 5 сек (Seedance Fast, ~$0.11/клип) + ретраи ×3 =
**~$4** на весь батч. Бюджет $100 из канона батч №1 почти не трогает.

**Чего в батче намеренно нет:** ни одного ролика про reseller-тариф (узкая
аудитория, канон велит держать её вне общих форматов) и ни одного обещания
кэшбэка / промокодов / «гарантии лучшей цены» — этого в продукте нет.

## Что мерить

Через 2–3 недели после заливки — `scripts/sql/attribution-report.sql`:
свод по семействам `f1…f5` и разрез по конкретным роликам. Решение принимаем по
**стартам бота**, не по просмотрам: у F4/F5 просмотров будет кратно больше, и это
ожидаемо не значит, что они выиграли.
