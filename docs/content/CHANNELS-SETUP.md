### Дубли на VK / MAX
Тот же текст, меняется только ссылка на бота:
- VK: `https://vk.me/tryberrybot?ref=v_dir_vkgroup` — метка в VK это **`?ref=`**, а не
  `?start=`; скопировать TG-вариант = молча потерять атрибуцию.
- MAX: `https://max.ru/se13426918_bot?start=v_dir_maxchannel`

### Прятать payload от пользователя
Цель — чтобы в посте не торчало `?start=v_dir_...`. Решение по площадкам:
- **TG** — гиперссылка под текстом (Ctrl+K). Работает, ничего не стоит, payload не виден.
- **VK** — НЕ прячем, ссылка голой строкой в посте (решено 2026-07-14). Маскировка
  внешних ссылок в постах запрещена (`[club123|текст]` — только внутренние vk-страницы),
  кнопок у обычных записей на стене нет (только у промопостов). Кнопка действия
  сообщества не спасает: она в ШАПКЕ сообщества, а не в посте, и «Написать сообщение»
  в её списке типов НЕТ (проверено) — есть только позвонить / открыть приложение /
  открыть сайт / написать на почту. Кнопка «Сообщение» появляется в шапке сама, если
  включены сообщения сообщества. Городить «Открыть сайт» → vk.me не стоит: подпись не
  та, ref на такой дорожке под вопросом → потеря атрибуции дороже косметики.
- **MAX** — поддержка inline-ссылок неизвестна, проверить черновиком; при неудаче
  оставить голую ссылку (аудитория пока минимальная).
- **Редирект `tryberry.ru/go/<метка>` → 302** — решено НЕ делать (2026-07-14): лишний хоп
  через браузер вместо прямого открытия приложения. Прячем только средствами площадок.
