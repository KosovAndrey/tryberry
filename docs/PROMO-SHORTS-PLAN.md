# Продвижение: 30–60 коротких видео (Reels / Shorts / VK Клипы / TikTok)

Дата: 2026-07-11. Статус: план, производство не начато.
Бюджет на генерацию: **$100**. Ритм: 1 видео/день, потом перезалив/ремиксы.
Цель: протестировать форматы → найти тот, что даёт **переходы в бота** (не просмотры).

---

## 1. Главный вывод (TL;DR)

**Чистый Kling на 60 роликов не влезает в $100 и, что важнее, не показывает продукт.**
Рекомендуемая связка — гибрид:

- **Ядро ролика** — скринкаст бота + анимации наших реальных данных (история цен,
  фейковые «скидки» WB) — это почти бесплатно и это наше уникальное преимущество:
  ни у одного конкурента нет такого видеоряда, а у нас он генерится кодом.
- **Хук (первые 1–3 сек)** — AI-генерация: Seedance 2.0 Fast (~$0.11 за 5-сек клип
  через API) на объём + Kling/Veo для 10–15 «геройских» хуков.
- Бюджет: ~$25 Seedance + $37 Kling Pro (1 мес, опционально) + $5 ElevenLabs
  (или бесплатный edge-tts) = **$67, с запасом**.

Kling Pro сам по себе: $37/мес = 3000 кредитов ≈ 75 генераций 5-сек 1080p ≈
**~25 финальных клипов** при 3 дублях. На 60 полноценно-AI роликов (по 3–5 сцен)
нужно 500–1000 генераций — это $150–300 и 2–3 месяца подписки. Не наш путь.

## 2. Сравнение подходов к производству

| Подход | Стоимость на 60 шт | Плюсы | Минусы | Вердикт |
|---|---|---|---|---|
| **A. Чистый AI-видеоряд** (Kling/Veo целиком) | $150–300+ | вау-картинка, без съёмок | продукт не виден → низкая конверсия; «AI-слоп» приелся, алгоритмы и зрители научились скипать; дорого на объём | только как 1 тестовый формат |
| **B. Скринкаст-демо бота** | ~$0 | показывает продукт, честно, быстро | слабый хук, нужен монтаж | ядро, но нужен хук сверху |
| **C. AI-аватар** (HeyGen и пр.) / сам на камеру | $29+/мес / бесплатно | «лицо» повышает доверие | аватары с русским липсинком палятся и убивают доверие; сам на камеру — время и стабильность ритма | не сейчас; вернуться, если захочется личного бренда |
| **D. Гибрид: AI-хук → демо → CTA** | ~$25–60 | залипательный старт + продукт + конверсия | сборка из двух источников (шаблон решает) | ✅ **основной** |
| **E. Data-driven анимации кодом** (Remotion/AE: графики реальных цен) | ~$0 (1–2 дня на шаблон) | уникальный контент из нашей БД, автогенерация десятками, идеально для «разоблачений скидок» | суховатая картинка без обвязки; стартовые затраты времени | ✅ **второй столп**, комбинировать с D |

Почему D+E, а не что-то одно: для utility-продукта конвертит момент
«вижу, как это работает, и вижу выгоду в рублях». AI-картинка это не даёт,
скринкаст без хука не переживает первые 1.5 секунды. Гибрид закрывает оба конца
воронки, а данные из нашей БД (реальные графики цен) — контент, который нельзя
скопировать без нашего продукта.

## 3. Генераторы видео: что выбрать под хуки (цены июль 2026)

| Модель | Цена | Комментарий |
|---|---|---|
| **Seedance 2.0 Fast** (API: fal.ai / Atlas Cloud) | ~$0.022/сек → 5-сек ≈ $0.11 | лучшая цена/качество на объём, продакшн-уровень; **основная рабочая лошадка** |
| **Kling 3.0** (подписка Pro $37/мес, 3000 кр.) | 5-сек 1080p ≈ 40 кр. → ~75 генераций | эталон по кинематографичности движения; брать 1 месяц на «геройские» хуки, если Seedance не дотянет |
| **Veo 3.1** (API) | Lite $0.05/сек, Fast $0.15/сек, Standard $0.40/сек | лучший общий уровень + нативный звук; Lite — запасной вариант |
| Hailuo / PixVerse | дешёво | вариант Б на скорость, качество ниже |

Практика: хуки делать **без говорящих персонажей** (русский липсинк — слабое место
всех моделей) — визуальная драма + закадровый TTS-войсовер. Озвучка: ElevenLabs
multilingual ($5/мес хватит) или бесплатный `edge-tts` (голоса Дмитрий/Светлана —
для теста форматов достаточно).

## 4. Тест-матрица форматов (5 × 12 = 60)

Идея теста: не «60 разных видео», а **5 форматов по 12 штук**, чтобы по каждому
набралась статистика. Внутри формата меняем только тему/товар.

| # | Формат | Из чего собран | Гипотеза |
|---|---|---|---|
| F1 | **«Скидка-обман»**: реальный товар WB, график показывает, что «−60%» — это цена месячной давности | Remotion/AE-анимация графика из нашей БД + TTS | виральность на возмущении; наш киллер-контент |
| F2 | **«Цена упала»**: товар подешевел на N₽, бот прислал алерт первым | скринкаст алерта + анимация цифр | прямая демонстрация ценности |
| F3 | **AI-хук + демо**: сценка боли (человек видит, что переплатил) → «кинь ссылку боту» → скринкаст | Seedance-хук 3 сек + скринкаст | классика перформанс-крео |
| F4 | **Лайфхак покупателя**: «3 ошибки при покупке на WB/Ozon», бот в конце как инструмент | TTS + стоковые/AI кадры + титры | полезность → сохранения/шеры |
| F5 | **Тренд/мем**: популярный звук/шаблон недели, адаптированный под «я после того, как узнал реальную цену» | по ситуации | дешёвый охват, лотерея |

Перезалив через 30–60 дней: платформы режут точные дубликаты — при перезаливе
менять хук/первые кадры, зеркалить, пересобирать под другой звук. Либо сразу
делать 30 уникальных × 2 варианта монтажа.

| Площадка | Статус | Тактика |

Вывод: контент один, но **KPI считаем по VK Клипам и YT Shorts**; IG/TT — бонус-дистрибуция.

## 6. Атрибуция — обязательный пре-реквизит

Тест форматов без замера переходов бессмыслен. До первого видео:

1. **TG**: deep-link `t.me/<bot>?start=v_<формат>_<площадка>` (например `v_f1_yt`),
   payload писать в БД при /start. Проверить, что стартовый payload сейчас
   сохраняется; если нет — маленькая фича (таблица источников или поле в users).
2. **VK**: аналогично `vk.me/...?ref=` — VK передаёт ref в start-событии.
3. Сайт как посадочная для IG/TT (ссылка в bio): `tryberry.ru?utm_...` → кнопки
   TG/VK ботов уже есть в hero.
4. Раз в неделю: сводка «формат × площадка → старты бота» (SQL достаточно).

Решение о победителе — через 2–3 недели: переходы в бота > досмотры > лайки.
