# Куда подаваться: разбор рынка на 31.08.2026

Собрано после отказа Путешествий (причина – «большой уклон в Go, нужен был
Java-стажёр») и фриза в Такси. Сроки проверять перед подачей – они меняются.

**Вводная, которая всё определяет: Андрей НЕ студент.** Учёба закончена, потом
армия, потом 1,5 года техписателем в Яндексе (до апреля 2026), с апреля – свой
продукт. Большая часть стажёрских программ – студенческие, поэтому первый
фильтр всегда «берут ли без статуса студента», и только потом стек.

---

## Три вывода про рынок

**1. Прямых junior-вакансий на Go почти нет.** На Хабр Карьере из 30 вакансий Go
junior – одна (~3%). Рынок Go – это мидлы и сеньоры; джунов берут почти только
через стажёрские программы, где есть выделенные ставки под неопытных.

**2. Java расширяет воронку.** Java/Kotlin-направлений в программах ощутимо
больше, чем Go, и junior-вакансий на Java тоже больше. В проде есть Spring
Boot 3.5 / Java 21 (price-insight: Spring Kafka, Kafka Streams на Processor
API, exactly-once, Micrometer, actuator + свой HealthIndicator, Testcontainers)
– это законный Java-опыт, который сейчас не проговаривается.

**3. Главный актив – продукт, а не резюме.** Прод, платящие пользователи,
микросервисы. Часть работодателей (Wildberries прямо) смотрит портфолио
вместо диплома – для не-студента это основной вход.

## Берут БЕЗ статуса студента

### Wildberries – приоритет №1

Почему первый: **Go – около 80% микросервисов**, статус студента не обязателен,
и в 2026 компания явно смотрит на self-taught с сильным портфолио. То есть
ровно твой профиль, и то, за что тебя завернули Путешествия, здесь плюс.

- Больше 1500 стажёров в год: Go, Python, Mobile, DevOps. Также берут junior
  на Go, Java, Python.
- Оплата: Москва 80–120 тыс. до налога, регионы чуть ниже. Удалёнка по России
  и СНГ, 20–40 часов.
- Конкурс ~45 человек на место, требования год к году жёстче.
- Этапы: скрининг резюме → алго-секция (3–4 задачи + практическое задание) →
  техинтервью 60–90 мин с лайв-кодингом → System Design Lite → софт-скиллы.
- Скрининг до 5 рабочих дней, дальше фидбек 2–3 дня после каждого этапа.
- Подача: `tech.wildberries.ru`, либо через агрегаторы (Young&Junior).
- Рекомендуют подавать за 3–4 месяца до желаемого старта.

### Т-Банк (Т-Старт) – приоритет №2

- **Статус студента не обязателен**, программа открыта для выпускников и
  начинающих специалистов.
- 30+ направлений, включая Go, Java, Scala, Python. **Подавать на два сразу.**
- Этапы: заявка → анкета → онлайн-экзамен 3–5 часов → интервью с кураторами →
  оффер. Ответ до 3 месяцев.
- 3–6 месяцев, 20–40 часов, удалёнка или офис. 2004 стажёра за 2025, 70%
  остаются в компании.
- Дедлайн по одному источнику – 6 сентября, по другому набор круглогодичный.
  Подавать сейчас.

### МТС

Осенне-зимний набор август–октябрь, старт в ноябре. Ориентируются на студентов,
выпускников буткемпов и свитчеров с базой – статус студента не барьер.

- **Andersen** – GO Trainee (Баку), аутсорс, берут охотнее.
- **Альфа-Банк** – набор до 31 декабря.

## Параллельный трек: junior-вакансии напрямую

Не заменяет программы, но и не ноль. На Go джунов почти не берут, на Java
вакансий заметно больше (Хабр Карьера, hh.ru, фильтр «без опыта» / 0–1 год).
Аргумент в отклике – не «хочу учиться», а продукт в проде с платящими
пользователями.

## Что подтянуть

1. **Алгоритмы – ворота везде.** У Т-Банка онлайн-экзамен 3–5 часов, у
   Wildberries алго-секция плюс лайв-кодинг, у Яндекса контест. Час в день,
   стабильно.
2. **Java-версия рассказа и резюме** – без неё половина дверей закрыта.
3. **JPA и `@Transactional` = ноль строк** – первый вопрос Java-команды.
   Спринт лежит в `~/projects/kotlin-spring-lab`.
4. **Публичное портфолио.** Wildberries смотрит GitHub. Репозиторий приватный
   на GitLab – значит для них видно только сайт. Стоит подумать, что можно
   показать публично: витрину проекта, разбор на Хабре, выделенный
   репозиторий.

## Чего НЕ делать

- Не тратить время на студенческие программы – X5, Route 256 отсеют по анкете.
- Не ждать ответа Пэя, прежде чем подавать остальное.
- Не считать отказ Путешествий сигналом о знаниях: причина названа, она про стек.
