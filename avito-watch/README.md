# avito-watch — новые объявления Авито в Telegram

Личный мониторинг выдачи (первый сценарий — аренда квартиры). Присылаешь боту
ссылку на выдачу с фильтрами, он раз в 3–5 минут открывает её в браузере и
шлёт каждое новое объявление: фото, цена, адрес и метро, продавец (имя, тип,
рейтинг), дата, начало описания. По уже виденным сообщает о снижении цены.

## Почему браузер

17-09-2026 домашний IP после двух голых curl получил 429 «Доступ ограничен:
проблема с IP»; мобильное API стоит за тем же файрволом. Поэтому headful
Chromium (patchright в Xvfb), как в ali-miner. Браузер живёт только на время
проверки, cookie сессии хранятся в профиле `/data/profile`.

## Как устроено

- `extract.py` — чистый разбор: SSR-стейт `<script type="mime/invalid"
  data-mfe-state>` → объявления; запасной путь — DOM `[data-marker="item"]`.
- `watch.py` — бот (long-poll через xray) + цикл проверок, SQLite в `/data`.
- Первая проверка подписки только запоминает выдачу. Дальше шлём объявления,
  которых не было; не виденные, но старше суток (продвижение, сдвиг выдачи),
  молча запоминаем. Больше 10 новых за раз — первые 10 и ссылка.
- Стена антибота: пауза 5 мин с удвоением до 2 ч, после 2 блоков подряд
  профиль стирается. О блоке и восстановлении бот пишет в чат.

## Команды бота

ссылка — подписаться; `/list`, `/del N`, `/check`, `/status`, `/dump N`
(сырые данные первых объявлений файлом — калибровать поля продавца).

## Env

| Env | Дефолт | Смысл |
|-----|--------|-------|
| `AVITO_BOT_TOKEN` | — | токен отдельного бота; без него сервис спит |
| `AVITO_ALLOWED_CHAT_IDS` | — | кого пускать, через запятую (чужому бот отвечает его chat_id) |
| `AVITO_TG_PROXY_URL` | `http://xray:8888` | egress в Telegram |
| `AVITO_BROWSER_PROXY_URL` | — | прокси браузера, если Авито забанит прод-IP |
| `AVITO_INTERVAL_MIN_SECONDS` / `MAX` | 180 / 300 | интервал проверки |
| `AVITO_FRESH_WINDOW_HOURS` | 24 | старше — не считаем новым |

## Проверка

```sh
python3 -m unittest test_extract            # разбор, без браузера
docker compose -f docker-compose.yml -f docker-compose.prod.yml run --rm avito-watch --probe '<ссылка на выдачу>'
```

Проба печатает заголовок, число объявлений и первые три в разобранном виде,
сырые кладёт в `/data/probe.json`.
