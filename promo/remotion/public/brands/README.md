# Логотипы маркетплейсов — файлов здесь нет намеренно

Это чужие товарные знаки, в git они не кладутся. Хук (`src/Hook.tsx`) умеет
показывать логотип приглушённым фоном, но по умолчанию выключен.

Чтобы включить:

1. Положить сюда PNG с прозрачным фоном, светлые версии (кадр тёмный):
   - `wb.png` — Wildberries
   - `ozon.png` — Ozon
   - `ym.png` — Яндекс Маркет
   Общая версия `mp` логотипа не получает: площадок там четыре.
2. В `src/Hook.tsx` переключить `LOGOS_READY` в `true`.

Брать с официальных брендбуков площадок, не из поиска картинок: там нужны
и разрешённые начертания, и прозрачный фон. Логотип рендерится крупно с
прозрачностью 0.22 — мелкие детали и слоганы в нём всё равно не читаются,
поэтому годится простая монохромная версия.
